# Comments/changes for AIMD-L proposal submission system
## Todd Hufnagel, 2026-09-14

1. Change access categories to:
- Johns Hopkins University
- External (academic/not-for-profit)
- External (corporate/industrial)
- External (government)
- External (foreign, non-US)

2. External users should also specify their organization (text field, presumably)

3. Need to specify data classification:
- Open (fundamental research)
- Confidential/proprietary (corporate data not for public release, not export controlled)
- Confidential/controlled (corporate or government data subject to export restrictions and/or CUI)
- Opt-out (neither confidential nor propritary but with restrictions on dissemination)

Probably we should have a link here to the data policy that describes these categories in more detail.

4. Public overview should only required for "open" and "opt-out" categories. Needs more guidance, maybe something like this:

"Provide a brief abstract describing the proposed research, including a statement of the problem, research objectives, kinds of materials to be tested, and experimental approach. This abstract will be publicly available after the proposal has been accepted."

5. Instruments - specify as follows:
- HELIX (laser microflyer impact/laser-driven shock)
- MAXIMA (x-ray diffraction/x-ray fluorescence spectroscopy)
- SPHINX (nanoindentation)
- Other (needs text field to describe)

6. Assistance question: Do you require assistance from AIMD-L staff for the experiments?
(yes/no)

7. Safety - should have a checklist of potential hazards
- Samples: None/Toxic/Flammable/Energetic/Biosafety/Radioactive/Other
- Other hazards: None/Laser (class 3-4)/High temperature/High voltage/Custom or user-supplied equipment
Then there should be a text box for them to provide description of the hazard(s) if any

8. Under team members:
- There should be a check box to indicate who is the PI
- Another checkbox for point of contact
- A check box about whether or not they are coming to AIMD-L (some may just participate remotely). 
- Not sure what "manager" means under role. PI and spokesperson are handled separately. Here I'd like to see indication of status: (faculty/senior investigator, staff, post-doc, grad student, undergrad, other)
- Should also indicate institution/company if not the same as the PI
- There should be a mention that ORCID numbers are required and provide a link to how they can get one.

9. Documents
- I don't think we need a CV for the PI.
- Need to provide some guidance on the proposal the user submits. This should be different for single instrument v. whole-lab proposals. See below.
- Should be able to attach a data management plan, if they have one

10. Funding (for academic/not-for-profit)
- Should specify funding agency and grant number 
- If internal JHU, provide budget/IO number

### Proposal for experimental campaign using 2+ Instruments (PDF? limit to 2 pages)

Proposal should include:
1. Context/motivation for experiment
2. Knowledge gap or scientific hypothesis to be addressed
4. Description of experiments to be performed (stations to be used, kinds of samples, measurements to be done, how data will be analyzed/used)
5. Expected data and outcomes (and how do these address the knowledge gap or answer the scientific hypothesis)
6. Estimate of number of days to be used (this can be a text box entry)


### Proposal for single-instrument use (can be HTML form)
1. Description of experiments to be performed (kinds of samples, measurements to be done, how data will be analyzed/used)
2. Number of days/half-days to be used
